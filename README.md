# <b>Разработка программного драйвера для управления адресной светодиодной лентой на базе чипа WS2812 с использованием микроконтроллера ATmega8 и AVR Assembly</b>

Проект представляет собой высокоэффективный программный драйвер для управления адресными светодиодами WS2812 (и совместимыми) на микроконтроллере ATmega8. Реализация выполнена полностью на языке ассемблера AVR для достижения максимальной точности временных задержек, необходимых для протокола WS2812. Драйвер поддерживает управление цветом каждого светодиода в ленте, динамическое изменение режимов работы и интеграцию с АЦП для интерактивного управления.

## <b>Описание проекта</b>

Адресные светодиоды WS2812 требуют строго определенных временных интервалов для передачи данных: каждый бит кодируется длительностью высокого и низкого уровня на линии данных. Стандартные библиотеки на C не всегда могут обеспечить необходимую точность из-за накладных расходов компилятора. Данный проект реализует драйвер полностью на ассемблере, что гарантирует:

- **Точное соблюдение таймингов** протокола WS2812
- **Минимальную задержку** между битами
- **Эффективное использование** ресурсов микроконтроллера
- **Полный контроль** над процессорным временем

### Возможности драйвера:
- Управление лентой из 8 светодиодов (легко расширяется изменением константы)
- 24-битное представление цвета (8 бит на канал)
- Три предустановленных цветовых режима
- Управление яркостью через АЦП (потенциометр)
- Прерывания по таймеру для смены режимов

## <b>Аппаратное обеспечение</b>

### Необходимые компоненты

| Компонент | Номинал/Обозначение | Количество | Назначение |
|-----------|---------------------|------------|------------|
| **Микроконтроллер** | ATmega8 | 1 | Основной контроллер |
| **Светодиодная лента** | WS2812B | 1 | Адресная лента |
| **Кварцевый резонатор** | 8 МГц | 1 | Тактирование |
| **Конденсаторы** | 22 пФ | 2 | Для кварца |
| **Конденсатор** | 100 мкФ | 1 | Фильтрация питания ленты |
| **Резистор** | 10 кОм | 1 | Подтяжка RESET |
| **Потенциометр** | 10 кОм | 1 | Управление яркостью/режимами |
| **Блок питания** | 5V, 2A+ | 1 | Питание |

### Подключение

| Вывод ATmega8 | Назначение | Подключение |
|---------------|------------|-------------|
| **PB0** | Data OUT | Вход DIN ленты WS2812 |
| **PB1-PB7** | (резерв) | - |
| **PC0 (ADC0)** | Аналоговый вход | Средний вывод потенциометра |
| **VCC** | Питание | +5V |
| **GND** | Общий | GND |
| **RESET** | Сброс | +5V через 10кОм |
| **XTAL1/XTAL2** | Кварц | 8 МГц + 22пФ |

## <b>Установка и компиляция</b>

### Требования к ПО

| Компонент | Минимальная версия | Назначение | Проверка установки |
|-----------|-------------------|------------|-------------------|
| **Atmel Studio** | 7.0+ | Разработка и компиляция | `avrasm2 -?` |
| **AVR-GCC** (опционально) | 4.8+ | Альтернативная компиляция | `avr-gcc --version` |
| **AVRDUDE** | 6.0+ | Прошивка контроллера | `avrdude -?` |
| **AVR Simulator** | - | Отладка | В составе Atmel Studio |
